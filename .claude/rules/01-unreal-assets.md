# 언리얼 에셋은 MCP로만 다룬다

`.uasset`, `.umap`은 바이너리다. Read/Edit/Write로 직접 열거나 수정하지 않는다. 텍스트로 보이는 부분이 있어도 마찬가지다. 직접 쓰면 에셋이 깨지고 에디터가 로드에 실패한다.

블루프린트, 레벨, 머티리얼, 데이터 에셋, 위젯 등 `Content/` 아래의 에셋을 읽거나 쓰라는 요청을 받으면 **먼저 `unreal-mcp` 스킬을 확인하고 해당 툴셋으로 처리한다.**

MCP가 응답하지 않으면 그건 도구 문제가 아니라 언리얼 에디터가 꺼져 있는 것이다. 우회해서 파일을 직접 건드리지 말고 사용자에게 에디터 실행을 요청한다.

## 예외 (일반 파일 도구를 쓴다)

- `Source/` 아래 C++ (`.h`, `.cpp`, `.cs`)
- `Config/` 아래 `.ini`
- `Docs/` 아래 마크다운
- `.uproject`, `.gitignore` 등 루트의 텍스트 설정 파일

## 되돌리기 어려운 작업

에셋 삭제·이동·이름 변경 전에는 `AssetTools.get_referencers`로 참조하는 에셋을 확인하고, 무엇이 깨질 수 있는지 사용자에게 알린 뒤 진행한다.
